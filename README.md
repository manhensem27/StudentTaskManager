A beginner-friendly Java console application built
using NetBeans.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks

## Technologies
- Java
- NetBeans
- Git
- GitHub

## How to Run
1. Clone or download this repository.
2. Open the project in NetBeans.
3. Run StudentTaskManager.java.
4. Follow the menu in the terminal.
